# Assignment 08: Capstone Maintainer Trial

## Period

Days 53-60

## Goal

Prove readiness for supervised real repo maintenance.

## Capstone Brief

Aqilah must complete one realistic maintenance task from start to finish in this assignment repo, using one of the source repos as reference.

She should choose one track:

1. `ee-admin-v5` track: design and test a safe fix for a sync/data handling issue.
2. `solar_calculator` track: design and test a safe fix for a validation, navigation, or migration issue.

## Required Workflow

1. Create a branch.
2. Write an investigation note.
3. Ask Codex for a plan.
4. Review the plan and identify risks.
5. Implement only in this assignment repo.
6. Add test or validation evidence.
7. Commit changes.
8. Open a PR.
9. Respond to mentor review comments.
10. Write a final readiness reflection.

## Required Files

Create:

- `submissions/08-capstone-maintainer-trial/investigation.md`
- `submissions/08-capstone-maintainer-trial/codex-plan.md`
- `submissions/08-capstone-maintainer-trial/implementation/`
- `submissions/08-capstone-maintainer-trial/validation.md`
- `submissions/08-capstone-maintainer-trial/pr-summary.md`
- `submissions/08-capstone-maintainer-trial/readiness-reflection.md`

## Required Final Reflection

Answer:

- What did Codex help you do faster?
- Where was Codex wrong, vague, or incomplete?
- What evidence proves your solution works?
- What would you check before touching production?
- What support do you still need from the team?

## Passing Standard

To pass the capstone, Aqilah must:

- Score `4` in Safety.
- Score at least `3` in Codex Usage, Technical Understanding, Verification, and GitHub Workflow.
- Explain the solution without reading directly from Codex output.
- Show clean GitHub history and a clear PR.

## Readiness Decision

After passing, she may start supervised real repo tasks:

- Documentation updates.
- Small tests.
- Low-risk bug reproduction.
- Low-risk UI copy or validation fixes.
- Investigation reports for production issues.

She should not yet independently run production migrations, change deployment settings, rotate secrets, or push urgent hotfixes without mentor review.
